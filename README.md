Power BI Sales Analysis Dashboard

Project Overview

An interactive sales dashboard built using Microsoft Power BI to analyze sales performance and identify business insights.

Tools Used

- Microsoft Power BI
- Power Query
- DAX

Key Features

- Sales performance analysis
- Product and category analysis
- Sales trend visualization
- Interactive charts and slicers
- Business insights through data visualization

Project File

Download the "Sales Analysis Dashboard.pbix" file from this repository and open it using Power BI Desktop.

Objective

To transform sales data into meaningful insights and support data-driven business decisions.
